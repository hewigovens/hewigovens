### Rust Libraries & Tools
- [🔐 hw-core](https://github.com/hewigovens/hw-core) – Cross-platform hardware wallet interface with Trezor Host Protocol support.
- 🎛️ Control Room – Unified session control interface for different coding agents (Claude, Codex, etc.) with JayJay's diff UX.
- [🧮 clifpad](https://github.com/hewigovens/clifpad) – Native scratchpad for Cranelift IR: agents write CLIF, it JIT-compiles and runs in an isolated worker, and every run reports value, optimized IR, disassembly, and timing. Ships an MCP server.
- [⛓️ solana-primitives](https://github.com/hewigovens/solana-primitives) – Core primitives for Solana blockchain development.
- [🦀 reqwest-enum](https://github.com/hewigovens/reqwest-enum) – Type-safe, enum-style HTTP API for reqwest.
- [📦 aya-devcontainer](https://github.com/hewigovens/aya-devcontainer) – Pre-configured Docker image for eBPF programming with Rust.

### macOS Apps
- [🐦 jayjay](https://github.com/hewigovens/jayjay) – Native macOS GUI for Jujutsu (jj) version control. Rust core + SwiftUI shell.
- [🚀 Remote Launcher](https://github.com/hewigovens/remote-launcher) Native macOS launcher for multiple High Performance Screen Sharing sessions.
- [🌐 MISO](https://github.com/hewigovens/Miso) – Lightweight menu bar HUD overlay for quick input method switching.
- [🕵️ app-detective](https://github.com/hewigovens/app-detective) – Detect macOS apps' GUI tech stack.
- [👻 ghosttile-cli](https://github.com/hewigovens/ghosttile-cli) – Hide apps from the macOS Dock (CLI, menu bar app, and Raycast extension). [Website](https://ghosttile.hewig.dev).
- [🚀 StagedLauncher](https://github.com/hewigovens/StagedLauncher) – Manage and delay app launches across stages on your Mac.

### iOS Apps
- [🎧 hearvia](https://github.com/hewigovens/hearvia) – Live translated subtitles for anything you hear, on iPhone and Mac. Apple on-device, OpenAI Realtime, Gemini Live, or a local model.
- [🕐 anytime](https://github.com/hewigovens/anytime) – Timezone-aware world clock for Mac and iPhone. [App Store](https://apps.apple.com/us/app/anytime-timezone-calculator/id1291735859).
- [🔍 inspect](https://github.com/hewigovens/inspect) – iOS/macOS app with Safari web extension, share extension, and passive TLS monitoring for HTTPS certificates. [App Store](https://apps.apple.com/us/app/inspect-view-tls-certificate/id1074957486).
